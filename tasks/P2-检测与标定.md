# P2 检测、标定、倾斜补偿

**阶段目标**：在静止条件下把"测得准"做扎实。需要达到的指标是 M1（静态精度）、M2（静态噪声）、M3（倾斜精度）。

**本阶段需要的实物**：P1 中的全部实物，另外还需要：

- 3 个哑光黑色参考标记（用电工胶带剪成 5×4mm），贴在与刻度相对的槽沿上（见 07-B7，贴之前要和全队确认）
- 手机测角仪或数显角度尺
- 一组垫块（用来把摆杆垫成 ±3°、±6°、±10° 等固定角度）
- 水平尺

**质疑要求**：这一阶段最重要的两个假设，都要用数据来检验：

1. 两种检测器至少有一种能满足 M6；
2. 射影补偿在真实镜头（有畸变）下仍然有效。

如果数据显示假设不成立，**不要硬调参数掩盖问题**，要写进报告并提交 CR。

## P2-T01 检测器 A 与 B

**目标**：按 04 §3、§4 实现两种检测器，并提供统一接口。

**要求**：

1. 统一接口：
   ```
   detect(roi_img_or_array, ctx) -> (found: bool, u: float, quality: int, diag)
   ```
   - `ctx` 包含预测位置、背景、参数等；
   - `diag` 是诊断信息（SNR、候选数、峰值等），只在调试或遥测时使用。
2. 两个检测器都要在**板上**和**电脑上**运行，并且结果一致：同一帧图像，两边算出的 u 相差 ≤ 0.05px。附一致性测试。
3. 参数全部从 `config.json` 读取。
4. 单元测试用合成数据覆盖以下情况：
   - 亮球、暗球、带高光的球
   - 背景渐变、噪声
   - 有干扰物
   - 球停在两端
   - 球和干扰物挨在一起
5. 在 P1-EXP04 的数据集上先跑一遍离线评测，得到初步结果。

**验收标准**：

- [ ] `pytest -q` 通过。
- [ ] 板上和电脑上的结果一致性测试通过。
- [ ] 两个检测器在板上的单帧耗时 p95 都 ≤ 3ms（推荐配置下，附数据）。

## P2-T02 参考标记检测与射影补偿

**目标**：按 04 §2、§6 实现。

**要求**：

1. 实现 `markers.py`（标记检测）和 `geometry.py`（射影拟合、相似变换退化处理、查表插值）。
2. 单元测试：
   - 用合成的倾斜图像（02 §2 的模型，θ = 0、±6°、±20°）验证补偿后的残差和理论值一致：在无噪声的理想模型下，θ = 20° 时残差 < 0.5mm。
   - 测试 3 种退化路径：只有 2 个标记、没有标记、射影方程组病态。
3. 板上耗时：3 个标记的检测加上补偿，p95 ≤ 1ms。

**验收标准**：

- [ ] 测试通过。
- [ ] 板上耗时达标（附数据）。

## P2-T03 标定工具与快速复核 🖐

**目标**：按 04 §5 实现交互式的完整标定和快速复核。

**要求**：

1. 板上部分负责采集和计算，电脑端工具（`tools/calib/`）负责提示操作员、显示进度和结果。
   - 提示文字要非常具体，例如："请把磁铁贴在管子下方，把钢球吸到 +30 刻度处，让球心对准刻度线，完成后按回车"。
2. 输出 `calib.json`（ICD §5.2）和标定报告（锚点表、交叉验证误差、曲线图）。
3. 实现快速复核：3 个点，判定通过或不通过，结果写入 `check_*.json`。
4. 实现指纹校验：修改 `config.json` 中与指纹相关的一项后，旧标定必须被拒绝（附测试）。
5. 🖐 由队员**独立**按照工具提示完成一次标定，并计时，作为 M13 的初测。

**验收标准**：

- [ ] 完整标定的结果单调；交叉验证的最大误差 ≤ 1.0mm（初值，最终以 EXP-07 的结论为准）。
- [ ] 快速复核能正确判定：故意把摄像头碰歪 3mm 后，复核必须**不通过**（🖐 需要队员配合，附证据）。
- [ ] 队员完成一次完整标定的用时有记录。

## P2-EXP06 检测器对比与选型

**问题**（ADR-04）：检测器 A 和 B 哪个更好？默认用哪个？另一个作为交叉校验是否有价值？

**方法**：

1. 离线：在 `appearance_v1` 的全部数据（L1–L5、所有补光摆法）上评测 A、B，再加上对照组 B'（单行扫描线，【调研：kevin】）。
2. 在线：在推荐的补光（L2）下，板上实时运行 A 和 B（同一帧两个都跑），连续 20,000 帧，球自由或手推往返滚动。
3. 指标：
   - 有效率、误检率（方法见 06 T2）
   - 静态精度和噪声（标定后）
   - 单帧耗时
   - 两端的表现
4. 做敏感性分析：每个检测器的关键阈值（A 的 k，B 的 snr_min）在 ±30% 范围内变化时，上述指标怎么变。**对参数不敏感，比最优值稍好更重要。**

**产出**：对比表和推荐结论。结论要明确写出：默认检测器是哪个、备用检测器是哪个、要不要启用交叉校验，以及启用的规则。

**验收标准**：

- [ ] 数据覆盖全部 5 种光照。
- [ ] 推荐的检测器在 L2 下满足 M6 的门槛（有效 ≥ 99.5%，误检 ≤ 0.05%）。如果都不满足，就写 FAIL，提交 CR，并提出改进方向（光照、管子颜色或 YOLO 后备）。

## P2-EXP07 标定方法、点数、插值方式、磁铁影响 🖐

**问题**（ADR-06）：

- 25 个点够不够？13 个点行不行？
- 线性插值和 PCHIP 插值哪个更好？
- 磁铁会不会让钢球偏离刻度位置？

**方法**：

1. 🖐 做一次加密标定：从 −120 到 +120mm，每 5mm 一个点，共 49 个点。
2. 离线抽取子集：每 10mm 一个点（25 个点）、每 20mm 一个点（13 个点）。用剩下的点作测试集，比较线性插值和 PCHIP 插值的误差。
3. 磁铁影响：在 5 个位置上，比较"磁铁吸住"和"不用磁铁、球自然静止"（摆杆调到非常水平，或者用一个很浅的软挡块轻轻挡住）两种情况下球心的读数差异。分别用人工读刻度和图像检测两种方式比较。
4. 对比"在图像上点击刻度线"的标定方法（ADR-06 中的方法 b）与"摆球"的方法：两种方法的系统偏差有多大？

**产出**：推荐的标定点数和插值方式，磁铁偏差的量化结果。

**验收标准**：

- [ ] 4 个问题都有数据支持的结论。
- [ ] 推荐方案的测试集误差：最大 ≤ 1.0mm，RMS ≤ 0.5mm。

## P2-EXP08 倾斜误差与补偿效果 🖐

**问题**（ADR-03）：在真实镜头和真实安装条件下，射影补偿能把误差降到多少？

**方法**：按 06 T3 执行，并扩展到以下内容：

1. 角度：−10°、−6°、−3°、0°、+3°、+6°、+10°。另外按 07-A15 给出的最大倾角补测一个角度。
2. 位置：−100、−50、0、+50、+100mm。
3. 对比 4 种处理方式：不补偿、两标记相似变换、三标记分段线性、三标记射影变换。
4. 平移和振动模拟：摄像头支架左右平移 ±3mm、高度变化 ±5mm 时，比较补偿前后的误差。
5. （可选）验证 F16：用射影参数估计倾角，和实测角度比较。

**产出**：误差表（不同角度 × 不同位置 × 不同处理方式），以及"补偿前后误差随角度变化"的曲线。根据结果给出判定：ADR-03 是否成立。

**验收标准**：

- [ ] 三标记射影补偿在 |θ| ≤ 6° 范围内的最大误差 ≤ 3.0mm（M3）。
- [ ] 如果不满足，提交 CR，并按 ADR-03 的推翻条件给出下一步建议。
