
# P0-T03 操作清单

适用设备为幻尔 CanMV K230，编号按官方 40-pin 扩展排针图。需要万用表与一根杜邦线。夜间只准备脚本，电平和回环均待现场实测。

1. 确认 40-pin 排针的方向。TX 是**物理 8 脚**，RX 是**物理 10 脚**，GND 可用**物理 6 脚**。先保持 8、10 脚没有连接。 [幻尔官方排针图](https://drive.google.com/file/d/1fyYrIYiwkt6sV28TWa5HJUjMTVXZVHUW/view)
2. 万用表调直流电压档。Codex 启动 voltage 阶段后，等出现 HCV_UART_TX_READY，黑笔接 6 脚，红笔接 8 脚，记录一项稳定读数。任务验收范围为 3.0–3.5 V。
3. 检查读数通过后，等 voltage 脚本退出并断电。用一根杜邦线只连接 8 脚和 10 脚，再接回 USB 供电。第 1、2、4、17 脚是电源脚，底部 6-pin 是调试排针；这些脚保持原状。
4. Codex 启动 loopback 阶段。三种速率各发 10,000 帧，记录数据不一致、短读与短写。测试结束后断电取下杜邦线。

## Codex 运行命令

    python tools/board/uart_bench.py voltage --port COM3 --log reports/data/P0-T03/voltage.log
    python tools/board/uart_bench.py loopback --port COM3 --log reports/data/P0-T03/loopback.log
    python tools/analysis/p0_t03_results.py reports/data/P0-T03/loopback.log

电压读数由现场记录。两阶段结束都会尝试释放 UART 并恢复原先的 IO 功能映射。当前验证包括电脑端语法和汇总测试，硬件结果留待现场。
