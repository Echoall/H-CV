# M4 自启动方案

**提请 Manager 审批。本文是方案，尚未部署和验收。** 目标是在幻尔 K230 上安全启动测量，出现故障时让控制组收到明确状态，并能用 TF 卡或 USB 进入维护。

## 上电流程

1. 先在电脑备份原 `/sdcard/main.py`、当前提交、配置和标定，并记录 SHA-256。准备一张已经在本板启动过的备用 TF 卡。
2. 批准后，根目录的 `main.py` 只负责检查安全开关并启动 `/sdcard/hcv/` 的程序。先查 `SKIP_AUTOSTART`，再查已经实测的按键，保留 1.5 秒 USB Ctrl-C 窗口。然后再导入相机相关模块。
3. 启动程序先校验配置和标定指纹，初始化 UART1、摄像头和空场参考，做安装自检。未装载匹配标定时发 `NO_CALIB` 和 `CALIB_OK=0`。安装自检不过时发 `DEGRADED` 和 `err=5`。串口可用时按 ICD 每 0.5 秒发 `STATUS`，相机可用时照常发 BALL，包括球丢失帧。
4. 自检通过才进入 `READY`。MCU 看到匹配标定且没有故障后才允许开跑。初始化图传晚于可用的测量链路。图传错误只更新图传状态和日志，测量和 UART 继续工作。

## 逃生与重复复位

- **TF 卡开关**。断电后在 `/sdcard/hcv/` 创建空文件 `SKIP_AUTOSTART`，重新上电进入 USB REPL。修复后断电取卡，删除标志再重新上电。
- **按键开关**。若能确认有空闲、上电时可读的按键，在配置中写入实测的 GPIO 和有效电平。当前 `button_gpio=null`。先核对引脚与 UART、相机、启动脚的冲突，并验证按住和放开两种情况。
- **USB 开关**。上电等待期间从 USB 单独发送一个 Ctrl-C 字节 `03`。根启动程序捕获中断后退回 REPL。
- **复位限制**。建议在 TF 卡维护一个小型启动状态记录，通过临时文件加重命名更新。首次启动记 `STARTING`，正常进入 `READY` 后记 `RUNNING`。下一次上电若读到 `STARTING`，停在维护状态。读到非正常结束的 `RUNNING` 时只允许一次自动恢复，并先记 `RECOVERING`。若 `RECOVERING` 后再次重启，停在维护状态。正常结束服务后清除状态记录。当前固件盘点没有 `machine.reset_cause()`，突然断电和运行期复位走同一恢复规则。赛前先实测这条限制与正常断电操作是否适配。

## 看门狗和失效状态

| 情况 | 计划行为 |
|---|---|
| Python 能退出且单次处理超过 500 ms | 记录阶段、时长和 `err=7`，通过 `finally` 停相机、释放媒体和 UART。间隔约 1 秒再初始化，连续 3 次失败进入 `FAULT`。 |
| 取帧超时 | 将取帧等待上限和软件监控对齐，报 `err=2`，经同样的有界恢复路径处理。 |
| Native 相机、编码或媒体调用卡住，Python 无法推进 | 启用硬件 WDT 后只在测量主循环完成取帧、检测和 UART 发送后喂狗。正常无球帧可以喂狗。卡住不喂，等板重启，由启动状态记录阻止重复卡死。 |
| 多次故障或按下逃生开关 | 故障恢复路径有 UART 时保留 `FAULT` 心跳。进入维护时保留 REPL。MCU 对 `FAULT` 或 100 ms 无合法 BALL 执行安全动作。 |

此前独立探针调用 `WDT(1, 3)` 后停止喂狗，两次都观察到 USB 断开、uptime 归零并重新连接 COM3，末次喂狗至主机观察到 USB 断开约 5.60 秒。这个时间包含系统和 USB 路径，赛前仍要在目标启动程序里测量从超时到重新可控的完整时间。硬件 WDT 在安全开关检查之后启用。当前固件公开的 WDT 接口只有 `feed`，计划按启用后不能主动停狗设计。维修模式在启动时不启用 WDT。[原始普通探针](data/M4/wdt-probe.log) · [原始显示异常探针](data/M4/wdt-lcd-probe.log)

## 实施顺序与验收

1. Manager 批准后先用 USB 手动运行启动原型，验证异常注入、单次恢复和连续失败限制，并复测原板日志中连接断开后的主机端回收。
2. 在备用卡逐一验证文件、按键、Ctrl-C 逃生。分别模拟取帧超时、Python 异常、硬件 WDT 复位。每次保留日志、USB 可达性、`STATUS` 与 MCU 安全输出，不改变正式卡。
3. 按 SOP 启动并记录上电到 `READY`、第一帧可信 BALL、RTSP 能回放以及控制组确认的计时。通过后才将相同内容部署到比赛卡。回退时先断电，换回已验证的备用 TF 卡或恢复原 `main.py`。

依据 [算法规格 §9](../docs/04-算法规格.md)、[ICD §3](../docs/03-接口规范-ICD.md) 和 [MVP 路线](../tasks/MVP-路线.md)。
