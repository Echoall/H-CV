# M2 水平尺标定与现场采集

K230 固件 `v1.4-19-ga7de1c8`，MicroPython `1.21.0`。板上测试使用 `reports/data/M1/m1-config.json`。测试时未放钢球，未改板端正式标定。

## 标定与编号

相机、水平尺和球的测试区域固定后，先在空场采集全幅检测通道灰度图和 60 帧列剖面。输入尺面 ±12 cm 的大致像素列，选一条避开短刻度与数字的窄横带。程序在每个编号自己的窗口内找长刻度，计算亚像素列坐标。遮挡的刻度从 LUT 跳过，保留下来的记录仍使用原物理编号。横带可用 `--strip LEFT RIGHT TOP BOTTOM` 配置，球 ROI 使用板端有效 `config.json` 和 `config.local.json`。校准文件包含相机指纹、绝对像素位置和空场背景，板端运行时转换到 ROI 坐标。倾斜补偿保持关闭。

合成验收按 [Issue #5 最新 P2-T02b 指标](https://github.com/Echoall/H-CV/issues/5#issuecomment-7061601248)执行。水平尺长刻度 0.2/0.4 mm，1.71 px/mm 对应约 0.34/0.68 px。生成器按针孔模型投影，模拟短刻度、数字纹理、光学模糊、像素积分及图像噪声。三个亚像素相位分别测试无遮挡、跳过一条、两条、三条长刻度，覆盖端点被遮挡。24 个合成案例均正确编号 22–25 条长刻度，逐条误差 < 0.3 px，逐毫米复算 −120…+120 mm 的 LUT 误差 < 0.3 mm。合成宽度和误差用于验证程序，实拍时可读性取决于镜头对焦、纸尺、光线和机位。

```text
python -m pytest -q tests/test_m2_ruler.py tests/test_m2_field.py
```

## 一条命令引导

使用实测尺面角度替换示例中的 `0`：

```text
python tools/calib/m2_field.py reports/data/M2/session-01 --level-deg 0
```

脚本采集空场参考，引导选择长刻度条带并生成候选标定。正常照明测 0、±5、±10 和 ±12 cm。关灯与侧光各测空场和 0 cm。每个静态点必须至少有 100 帧有效位置，均值误差绝对值 ≤ 2 mm，另记标准差。空场必须至少采 100 帧且无 `VALID`。进入与拿走测试各录 8 秒，先播五声低音，采集开始约一秒后播高音。根据同步预览标出球首次进入或离开的帧，再计算 `VALID` 转换是否分别在 3 帧和 9 帧内完成。输出 `results.csv`、`results.json`、每步同步图像及 BALL 数据。纸尺代替槽体的布置和验收范围由 Manager 与用户确认。

标定文件激活前，脚本先保存并展示 `numbered-ruler.png`，标注每条识别到的长刻度并突出显示 0 cm。用户对照物理摆杆中心按 `Y` 后，脚本上传暂存文件。首次测量时将球对准尺面上实印的 0 刻度。用暂存 LUT 取得至少 100 帧有效位置，且均值绝对值小于 3 mm，才替换已有标定。端点同时故意偏移 +10 px 或 −10 px 的流程测试中，模拟真实零点读数偏约 10 mm，两个候选均被拒绝，已有标定未被替换。合成数据通过，真实零点确认和入口仍待现场。

## K230 无球冒烟

板上实拍生成 60 帧空场剖面和 640×360 灰度图。用同一指纹、实拍空场背景与独立的名义三锚点 fixture，8 秒录得 720 组相机 ROI 和 BALL 数据，序号、CRC 由解码器逐帧验证，720 帧均有 `CALIB_OK`，`VALID=1` 为 0。同步图像 160×12，最大相邻相机时间戳间隔为 15 ms，活动期丢帧为 0。脚本在第 89 帧发出主机播放高音的事件。此次验证检查了事件、板上数据和解码，人在现场是否清楚听见仍待确认。正式钢球、纸尺实物精度和灯光尚未验收。

```text
python tools/board/board.py run tools/board/m2_reference.py --timeout 30 --stream
python tools/board/board.py put reports/data/M2/fixture.json /sdcard/hcv/m2-calibration-fixture.json
python tools/board/board.py run reports/data/M2/dry-capture.py --timeout 38 --stream
python tools/analysis/m1_board.py reports/data/M2/empty-capture.log
python tools/analysis/m1_ball_evidence.py <capture.bin> <output>
```

原始日志、实际空场剖面、独立 fixture 和解码后的 BALL 记录位于 `reports/data/M2/`。完整原始同步图像文件保存在测试电脑上，SHA-256 为 `c7a67b1cf14163dc687940f8864f9017509556846a79fab95fb47d103721d8e8`。
