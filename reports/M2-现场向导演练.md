# M2 现场向导电脑演练

Issue #6 第 3 项，2026-11-26。代码基线 `4c67d04`，本版用 `git log -1 --diff-filter=A -- reports/M2-现场向导演练.md` 定位。电脑使用 CPython 3.14.6，采集配置来自 `reports/data/M1/m1-config.json`，固件与固件散列不适用。原始记录在 `reports/data/M2/field-wizard/`。

## 向导走过的步骤

双击 `station/bench/M2标定与验收.bat` 会先读板子 `info`，再提示输入尺面角度。准备好、按回车后，参考图与各采集段均有五声低音和一声由采集信号触发的高音。尺面标号由用户看图确认；进球和拿走的首帧由用户查看带帧号的录像。每段保存逐帧 BALL、ROI 录像及判定，退出时保存 `summary.json` 和文字报告。自检失败时报告标明尚未采集。USB 自检上限 20 秒，板端参考图、普通采集的命令上限分别为 30、38 秒，电脑另留 25 秒给连接与收尾。小文件传输上限 120 秒，二进制录像取回上限 600 秒。人工摆球或看图时由操作者控制进度。

电脑模拟通过文件替代 USB 和板端输出，用生成的尺图运行真实标定、编号预览和零点检查。每段经过实际的子进程、采集信号、取回文件、CRC 解码、生成编号视频、逐帧 CSV 和报告。模拟操作者从生成的视频像素找出进出帧。听觉和人手操作未测，提示词及信号顺序已存 `operator.json`。

| 电脑检查项 | 结果和证据 |
|---|---|
| 建立标定并校验 0 线 | PASS。生成 `calib.json`；先验证临时标定，再启用。零点数据见 `results.json`。 |
| 正常照明 0、±5、±10、±12 cm | PASS。每点输入 180 个有效合成测量值，均值等于设定位置，标准差为 0。 |
| 关灯和侧光分别测空槽和 0 点 | PASS。两种灯光的合成像素不同，空槽均为 0 个 VALID，有球为 180 个 VALID。正常灯空槽也完成。 |
| 进球与拿走 | PASS。两个视频均在第 92 帧首次变化。协议进球第 94 帧变化、拿走第 100 帧变化，含首帧分别为 3 和 9 帧。时间戳最大间隔均为 12 ms。 |
| 提示、导出和中断 | PASS。底图加 14 个记录段，共有 15 组五低一高信号；保存全部 14 行判定。另测电脑 `info` 超时，零次采集并保存未完成报告。 |
| 实物精度、实际灯光鲁棒性、钢球响应时间 | 待现场。合成 BALL 的位置和状态来自程序设定，数字用于验证字段、门槛及流程。 |

## 复现

```powershell
python -m station.bench.m2 --simulate --output station/bench/runs/m2-rehearsal-new
python -m pytest -q tests/test_m2_field.py tests/test_m2_wizard.py
```

使用尚不存在的输出目录。`synthetic-ball-csv.zip` 保存 14 段解码后的逐帧记录；重跑可重新生成所有合成二进制录像、标号预览和提示记录。此次改动补齐参考图的确认和高音信号，给传输与采集子进程增加了电脑端截止时间。现场不会运行模拟器。
