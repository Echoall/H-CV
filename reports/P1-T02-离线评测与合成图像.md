# P1-T02 离线评测框架与合成图像生成器

状态：`DOING`。

## 已完成

- `tools/synth/generate.py`
  - 生成槽、球、光照渐变、噪声、亮暗极性、高光、运动模糊、划痕和磁铁暗影。
  - 支持透视项参数。
  - 每帧同时输出像素级球心真值。
- `k230/hcv/compat.py`
  - CPython 使用 NumPy，板上使用 ulab.numpy。
- `k230/hcv/detector.py`
  - 与电脑端共用的列剖面检测器原型。
- `tools/eval/evaluate.py`
  - 读取合成 `.npy` 和板上 `.gray.bin` 数据。
  - 输出逐帧 CSV 和误差统计 JSON。
  - 支持 `ideal` 检测器验证评测框架口径。

## 示例数据

`reports/data/P1-T02/` 下保存了暗球和亮球合成场景、逐帧真值、理想检测器结果和列剖面结果。复现命令：

```text
python tools/synth/generate.py reports/data/P1-T02/synth_v1/scene_dark --count 3
python tools/synth/generate.py reports/data/P1-T02/synth_v1/scene_bright --count 3 --polarity bright
python tools/eval/evaluate.py reports/data/P1-T02/synth_v1 --detector ideal --output reports/data/P1-T02/ideal
python tools/eval/evaluate.py reports/data/P1-T02/synth_v1 --detector profile --output reports/data/P1-T02/profile
```
