# M2 放球备用标定

2026-11-23，按 [Issue #6 的标定方案](https://github.com/Echoall/H-CV/issues/6#issuecomment-7087521168) 实现和验证电脑端流程。本轮未连接 K230 执行采集或写入现场标定。

## 操作流程

- 默认 `--calib-mode ruler`，自动识别刻度和编号确认照常进行。
- `--calib-mode ball` 先采空槽参考，再依次在 `−12、−10、−5、0、+5、+10、+12 cm` 摆球。每个点按回车确认后才开始采集，并在板端发出开拍标记时播放一次高音。相机探针通过 USB 返回检测器的全图像素列，每次最多 120 帧。一个点至少需要 60 帧有效检测，以像素中位数作锚点。标准差超过 `0.3 px` 或有效帧不足时，提示重放该点。
- 七个点必须齐全，锚点两轴必须严格递增。生成的分段线性 LUT 保留相机配置指纹、空槽参考、样本数和标准差，文件注明 `method=ball`。先写待检文件。用户把球重新放回 0，至少有 100 帧有效测量且位置均值绝对值小于 `3 mm` 后，才激活正式文件。静态采集时长按配置帧率计算，例如 30 fps 用 4 秒。
- 如要比较两个 LUT，保留已过零点复核的主方案文件，再运行备用方案并传入 `--compare-with`。通过备用方案零点复核后，重新摆七个点。两套 LUT 用同一批独立采样的原始像素列计算各自的均值误差和 `ruler_minus_ball_mm`，写入 `lut-comparison.json`。该选项在本次会话执行七点对照。

```powershell
python tools/calib/m2_field.py station/logs/m2-ball-field --calib-mode ball --level-deg 0
python tools/calib/m2_field.py station/logs/m2-ball-compare --calib-mode ball --level-deg 0 --compare-with <RULER_CALIB_JSON>
```

`--level-deg` 填现场测得的角度。更换相机位置、尺子或检测区后需校准并重新采集。

## 电脑验收

使用 `640×96` 合成灰度球图，已知投影比例 `1.71 px/mm`、倾角 `0°`，加 `1.2` 灰度标准差的噪声。使用项目的 `ProfileDetector`，ROI 起始列为 `65`。标定七点各有 60 帧有效检测，共 420 帧，锚点标准差为 `0.0171–0.0329 px`。从 `−120` 到 `+120 mm` 每毫米另外生成一张独立合成图，种子 `10000–10240` 与标定种子 `0–59` 分开。241 张图全部检出，以实际检测器坐标输入 LUT，最大绝对误差 **0.0702 mm**，RMS **0.0231 mm**。初版的 `0.3555 / 0.3360 mm` 来自将无检测偏移的几何像素直接输入该 LUT，现撤回这组数值作为有效性结果。

| 验收项 | 结果 |
| --- | --- |
| 241 个位置误差均严格小于 0.5 mm | PASS |
| 拒绝缺点、少于 60 帧、非有限像素值、不稳定点和非单调锚点 | PASS |
| 不稳定点进入单点重试，其他点照常采集 | PASS，电脑端模拟 |
| 独立零点 `2.9 mm` 可激活，`3.0 mm` 拒绝覆盖 | PASS，电脑端模拟 |
| 两张 LUT 使用独立的一组七点采样、逐点输出误差差值 | PASS，电脑端模拟 |
| K230 实际采集、现场零点与两张 LUT 的实测差异 | 待现场测试 |

## 检测器像素偏移与坐标核对

每种条件用 49 张球图。对同一张图分别取起始列为 `65` 和 `0` 的 ROI，并用 `u_global = u_roi + ROI.x` 换成全图像素。两种 ROI 的结果最多相差 `0.0032 px`。表中偏移定义为 `检测列 − 几何中心列`。

| 球相对背景 | 左侧高光 | 平均偏移（ROI 起始列 65） |
| --- | --- | ---: |
| 暗 | 无 | +0.0016 px |
| 暗 | 有 | +0.5806 px |
| 亮 | 无 | +0.0008 px |
| 亮 | 有 | −0.3680 px |

暗球上，左侧高光抵消了一部分暗像素的权重，使检测质心向右偏移。亮球上，同一位置的高光增加了左侧的权重，质心向左偏移。刻度路径另用四个 `0 / 0.25 / 0.5 / 0.75 px` 的子像素相位，每个相位识别 25 根，最大单根误差 `0.0479 px`，各相位平均误差的绝对值均小于 `0.004 px`。无高光的球与刻度结果都围绕同一个整数列中心坐标，附带的对照测试覆盖 ROI 起点变化，本轮无需调整半像素约定。

### 现场对照怎么解读

刻度 LUT 将几何像素转换为毫米，球检测器的高光偏移会保留在读数里。本组合成条件下暗球偏移约 `+0.34 mm`，亮球约 `−0.22 mm`，均在 `2 mm` 误差预算以内。放球 LUT 用检测器输出建立锚点，可吸收标定时的偏移，光照改变后仍需重测。

现场用独立的七个位置同时评估两套 LUT，分别报告对真值的误差和 `ruler_minus_ball_mm`。在两张 LUT 固定时，后者主要反映标定条件下两张映射的差异。换光时还要比较各自对真值的误差，才能看出检测偏移是否变化。如果现场两套 LUT 的差值明显超过 `0.5 mm`、且放球 LUT 的独立真值误差更小，优先考虑放球方案。也可用独立实测确定刻度方案的球偏移修正项。

[合成原始像素、锚点及逐毫米误差](data/M2/ball-calibration-synthetic.json)可用以下命令复算。

```powershell
python tools/analysis/m2_ball_calibration.py
python -m pytest -q
```
