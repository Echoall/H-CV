# M2 放球备用标定

2026-11-23，按 [Issue #6 的标定方案](https://github.com/Echoall/H-CV/issues/6#issuecomment-7087521168) 实现和验证电脑端流程。本轮未连接 K230 执行采集或写入现场标定。

## 操作流程

- 默认 `--calib-mode ruler`，自动识别刻度和编号确认照常进行。
- `--calib-mode ball` 先采空槽参考，再依次在 `−12、−10、−5、0、+5、+10、+12 cm` 摆球。每个点按回车确认后才开始采集，并在板端发出开拍标记时播放一次高音。相机探针通过 USB 返回检测器的全图像素列，每次最多 120 帧。一个点至少需要 60 帧有效检测，以像素中位数作锚点。标准差超过 `0.3 px` 或有效帧不足时，提示重放该点。
- 七个点必须齐全，锚点两轴必须严格递增。生成的分段线性 LUT 保留相机配置指纹、空槽参考、样本数和标准差，文件注明 `method=ball`。先写待检文件。用户把球重新放回 0，至少有 100 帧有效测量且位置均值绝对值小于 `3 mm` 后，才激活正式文件。
- 如要比较两个 LUT，保留已过零点复核的主方案文件，再运行备用方案并传入 `--compare-with`。通过备用方案零点复核后，重新摆七个点。两套 LUT 用同一批独立采样的原始像素列计算各自的均值误差和 `ruler_minus_ball_mm`，写入 `lut-comparison.json`。该选项在本次会话执行七点对照。

```powershell
python tools/calib/m2_field.py station/logs/m2-ball-field --calib-mode ball --level-deg 0
python tools/calib/m2_field.py station/logs/m2-ball-compare --calib-mode ball --level-deg 0 --compare-with <RULER_CALIB_JSON>
```

`--level-deg` 填现场测得的角度。更换相机位置、尺子或检测区后需校准并重新采集。

## 电脑验收

使用 `640×96` 合成灰度球图，已知投影比例 `1.71 px/mm`、倾角 `0°`，加 `1.2` 灰度标准差的噪声。使用项目的 `ProfileDetector`，ROI 的起始列设为 `65`，用于验证像素坐标转换。七点各有 60 帧有效检测，共 420 帧。锚点标准差为 `0.0171–0.0329 px`。已知真值从 `−120` 到 `+120 mm` 每毫米取一点，共 241 点，最大绝对误差 **0.3555 mm**，RMS **0.3360 mm**。

| 验收项 | 结果 |
| --- | --- |
| 241 个位置误差均严格小于 0.5 mm | PASS |
| 拒绝缺点、少于 60 帧、非有限像素值、不稳定点和非单调锚点 | PASS |
| 不稳定点进入单点重试，其他点照常采集 | PASS，电脑端模拟 |
| 独立零点 `2.9 mm` 可激活，`3.0 mm` 拒绝覆盖 | PASS，电脑端模拟 |
| 两张 LUT 使用独立的一组七点采样、逐点输出误差差值 | PASS，电脑端模拟 |
| K230 实际采集、现场零点与两张 LUT 的实测差异 | 待现场测试 |
