# CR-P1-01 UART1 可选提速到 460800

状态为草案。默认波特率维持 115200，等待队员、控制组与 Manager 确认。

P1-EXP05 在幻尔 CanMV K230 上用 UART1 写入 19 字节，每个波特率测 1,000 次。115200 下写入 p50 为 1,813 µs，460800 下为 453 µs，调用每帧缩短约 1.36 ms。按 8N1 计算线路传输时间，19 字节在两档速率下分别约为 1.65 ms 和 0.41 ms。[原始汇总](../../reports/data/P1-EXP05/uart-probe.log)

建议把 460800 作为可选的联调配置，两端同步修改波特率，保持帧结构、CRC 和超时语义。控制组需确认 MCU 时钟和串口能稳定支持 460800。实车使用短线、共地和已确认的 3.3 V 电平。板上空载实验只测了发送调用，联调时需用实际线束与 MCU 验证接收、CRC 错误、序号连续性和超时保护。兼容性或稳定性未通过时，双方回到 115200。

批准后更新 ICD 的可选波特率与接入说明，并同步验证 K230 配置、MCU、嗅探器和模拟器。
