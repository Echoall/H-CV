# CR-P0-02 幻尔 K230 的 UART1 物理排针

幻尔官方资料包的引脚图显示，40-pin 扩展排针的物理 8 脚为 TX1（IO3），10 脚为 RX1（IO4），6 脚和 9 脚为 GND。2 脚和 4 脚标为 5 V。图中独立的 6-pin 调试排针对应 CPU0 与 CPU1 的 UART0、UART3。 [幻尔官方资料索引](https://wiki.hiwonder.com/projects/CanMV-K230/en/latest/docs/resources_download.html) · [原始排针图](https://drive.google.com/file/d/1fyYrIYiwkt6sV28TWa5HJUjMTVXZVHUW/view)

幻尔串口课程的接线步骤文字提到 UART3，但该页示例选用 UART1 的 IO3、IO4。建议以官方排针图定物理编号，保留 UART1 的 ICD 配置，修正 P0-T03 现场步骤中残留的 UART2 和物理第 2、3 脚表述。 [幻尔串口课程](https://wiki.hiwonder.com/projects/CanMV-K230/en/latest/docs/2_Basic_Course.html#_2-3-uart-experiment)

固件报告的型号及用户所购型号已经确认。TX 的 3.3 V 空闲电平和回环误码率仍需实测。双方接线时使用 TX/RX 交叉和共地，电源脚在独立供电时悬空。
