# 立创·庐山派 K230-CanMV（标准版，1GB）已核实资料

> 资料来源：立创开发板 wiki（wiki.lckfb.com/zh-hans/lushan-pi-k230/ 下的 WiFi、UART、原理图、Sensor API、FAQ、快速上手等页面），核实日期 2026-11-19。
> 标「待实测」的项必须在 P0 阶段由 Codex 在板上确认，并以实测结果为准。

## 1. 型号辨别

- 本项目用的是**标准版**「立创·庐山派K230-CanMV开发板」：外置 1GB LPDDR4 内存。
- **不是** Lite-K230D（内置 128MB）。两者的固件、部分引脚都不同，不能混用。
- 标准版固件文件名以 `CanMV_K230_LCKFB_` 开头。只支持从 TF 卡启动。

## 3. 串口

K230 有 UART0–UART4 共 5 个串口。**UART0 被系统（RT-Smart 控制台）占用，不能使用。**

| 串口 | 位置 | 标准版引脚 | 说明 |
|---|---|---|---|
| UART2 | GH1.25-4P 座（丝印 2） | GPIO11 = TX，GPIO12 = RX | **本项目默认用这个口连 MCU** |
| UART3 | GH1.25-4P 座（丝印 3） | GPIO50 = TX，GPIO51 = RX | 备用（注意：Lite 版是 GPIO32/33，不同） |
| UART1 | 排针 8/10 | GPIO03 = TX，GPIO04 = RX | 备用 |
| UART2 | 排针 11/13 | GPIO05 = TX，GPIO06 = RX | 与 GH1.25 座上的 UART2 是不同引脚，用 FPIOA 选择 |
| UART4 | 排针 3/5 | GPIO48/49 | 与 CSI0 的 I2C 复用，**不要用** |

GH1.25-4P 线序：1 = V（5V **电源**，不是信号），2 = RX，3 = TX，4 = GND。

### ⚠ 烧板警告（来自官方 FAQ）

- 据售后统计，**超过一半的 K230 主控损坏，是外部设备的 IO 电平过高造成的**。
- 有些廉价 USB-TTL 模块的 TX 是 5V 电平，**接上就会损坏 RX 引脚**，与有没有接 5V 电源脚无关。接线前必须用万用表测量对方 TX 的空闲电平，确认是 3.3V。
- K230 已经由其他方式供电时，**GH1.25 座上的 V 脚必须悬空**，只接 TX、RX、GND。

## 4. 已知的坑（来自同题开源作品，见 `同题开源作品调研.md`）

- 有队伍遇到过 K230 串口 TX 空闲电平为 0V 的情况，原因是 FPIOA 引脚映射配错或用错了引脚。**P0 阶段必须做串口回环测试。**
- 用 VLC 播放 RTSP，默认的 1000 ms 网络缓存会造成 1–2 s 延迟；设成 `network-caching=200` 后可以降到约 200 ms。
- 在 Python 里逐包复制编码数据（`bytes(...)`）会带来明显的 CPU 开销和 GC 抖动。应改用 `rtspserver_sendvideodata_byphyaddr()` 这类直接传物理地址的接口，或者让编码器直接绑定 sensor 通道。
- 用 Python 做 HTTP MJPEG 或 UDP-JPEG 推流的实测结果有好有坏（有队伍做到了 320×240@15fps，也有队伍只收到 2–3fps），而且会拖慢视觉主循环。
- 建议给 K230 提供独立、稳定的 5V/3A 供电；USB 5V 和外部 5V 不要直接并联。
- TF 卡要买官方推荐的正品。很多"系统起不来、IDE 连不上"的问题，最后查出来是 TF 卡。
