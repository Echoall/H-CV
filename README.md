# H-CV：2026 电赛 H 题「车载平衡滚球」视觉子系统

本仓库是 H 题 **CV 组** 的全部工作：用摄像头和立创·庐山派 K230 测出钢球在摆杆上的位置（单位 mm），通过串口实时发给控制组的单片机；同时把画面通过 WiFi 传到场外笔记本，实现实时显示、录像和回放（题目要求 1）。

```
摄像头 ──► K230（找球 + 换算 mm + 滤波）──UART──► 控制组 MCU（PID 控摆杆）
                │
                └──WiFi（RTSP 视频 + UDP 数据）──► 场外笔记本（显示 / 录像 / 回放 / 曲线）
```

## 协作流程

1. Manager 在 `tasks/` 写好某阶段的任务书和验收标准，推到 `main`。
2. 队员对 Codex 说：「按 AGENTS.md 执行 `tasks/` 中的 P0 阶段」。
3. Codex 在分支 `codex/P0` 上完成任务，自测通过后把代码、原始数据、报告推上 GitHub，并把看板状态改为 `REVIEW`。
4. 队员对 Manager 说：「验收 P0」。Manager 拉取分支，复核代码、重算指标；通过就合并并标 `DONE`，不通过就写出整改意见（`reports/review/`）。
5. 如果实验结果推翻了原方案，Manager 修订 `docs/` 并在决策记录里写明原因。
